堆叠注入是sql注入中一种比较特殊的注入方式，其注入的sql查询数量通常大于两条。

| 类型       | 本质           | SQL 数量 |
| -------- | ------------ | -----: |
| UNION 注入 | 扩展原查询        |    1 条 |
| 布尔盲注     | 改变原查询条件      |    1 条 |
| 时间盲注     | 利用原查询产生可观察差异 | 通常 1 条 |
| 堆叠注入     | 在原语句之后追加 SQL |   ≥2 条 |

## 堆叠注入的条件

堆叠注入需要一些特定的条件：

```
HTTP 请求
   ↓
Web 应用
   ↓
ORM / 数据库框架
   ↓
数据库 Driver
   ↓
数据库协议
   ↓
DBMS
```

任何一层限制多语句执行，都可能让堆叠失败。

比如数据库本身可能理解：

```
SQL_A;SQL_B;
```

但应用使用的数据库驱动可能默认禁止一次提交多个 statement。

因此判断堆叠注入是否存在，不能只问：

> “MySQL / PostgreSQL / SQL Server 支不支持？”

还应该问：

> “当前语言 + Driver + API + 配置 + DBMS 的组合是否允许多语句执行？”

这也是为什么实际安全测试中，同一个数据库在不同应用里的表现可能完全不同。

堆叠注入可以使用sqlmap。eg：

```bash
sqlmap -u "http://ctf-target/login" \
  --data="username=test&password=123" \
  -p username \
  --technique=S
```

`sql_mode=PIPES_AS_CONCAT;`
