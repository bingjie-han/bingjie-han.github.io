## PEAS 模型描述

PEAS 模型是人工智能中用于描述智能体任务环境的经典框架，包括四个部分：

- P（Performance Measure，性能度量）：衡量智能体完成任务的效果。
    
- E（Environment，环境）：智能体所处的外部环境。
    
- A（Actuators，执行器）：智能体采取行动、影响环境的方式。
    
- S（Sensors，传感器）：智能体获取环境信息的方式。

## 提示词工程

| 提示词类型 | 工作方式 | 优点 | 缺点 |
|---|---|---|---|
| 零样本提示（Zero-shot） | 不提供示例，直接通过指令让模型完成任务 | 简单高效，Token 消耗少 | 复杂任务准确性可能较低 |
| 单样本提示（One-shot） | 提供一个示例，引导模型模仿其格式或规律 | 易于控制输出格式 | 单个示例可能缺乏代表性 |
| 少样本提示（Few-shot） | 提供多个示例，让模型根据示例规律完成任务 | 提高任务理解能力和输出稳定性 | 消耗较多 Token，依赖示例质量 |
| 角色扮演（Role-playing） | 为模型指定角色、专业背景或行为规范 | 有助于控制回答风格和内容方向 | 无法保证专业知识的准确性 |
| 上下文示例（In-context） | 在提示词中提供背景信息、任务要求和参考示例 | 帮助模型理解任务场景与输出要求 | 上下文过长可能增加成本和干扰 |
| 思维链提示（CoT） | 引导模型将复杂问题拆解为多个步骤进行推理 | 适合数学计算、逻辑推理和复杂任务 | 增加 Token 消耗，推理过程仍可能出错 |
### 大模型的分词机制

**文本分词（Tokenization）** 是大语言模型处理自然语言的基础环节，其核心作用是**将人类可读的文本转换为模型能够处理的 Token 序列。** 常见的分词方式包括基于词（Word-based）、基于字符（Character-based）和基于子词（Subword）的分词。基于词的方式将完整单词作为处理单位，但容易产生词表过大和未登录词问题；基于字符的方式将文本拆分为单个字符，虽然词表较小，但会增加序列长度；基于子词的方式则结合两者优势，将高频词保留为完整 Token，将低频词拆分为更小的子词单元。现代大语言模型广泛采用子词分词技术，例如 BPE（Byte-Pair Encoding），通过不断合并高频相邻符号对来构建词表，从而平衡词表规模与文本表示效率。

#### 意义

  在实际运行过程中，模型首先通过 Tokenizer 将输入文本切分为 Token，再根据预先构建的词表将每个 Token 映射为唯一的 Token ID，随后通过 Embedding 层将这些离散编号转换为高维向量，交由 Transformer 网络进行语义建模与计算。模型生成内容时，则通过预测后续 Token，并将对应的 Token ID 解码为可读文本。分词机制不仅决定了文本在模型内部的表示方式，还直接影响输入序列长度、上下文窗口利用率、计算资源消耗以及 API 调用成本。合理的分词策略能够在控制词表规模的同时减少不必要的 Token 数量，提高文本处理效率，因此是大语言模型训练、推理以及 Agent 系统开发的重要基础。

| 分词技术                    | 核心原理                                    | 优点                          | 缺点                       | 典型应用      |
| ----------------------- | --------------------------------------- | --------------------------- | ------------------------ | --------- |
| BPE（Byte-Pair Encoding） | 从基本符号开始，反复合并出现频率最高的相邻符号对，逐步构建子词词表       | 算法简单、效率高，能够平衡词表规模与 Token 数量 | 依赖语料统计频率，分词结果不一定符合语义边界   | GPT 系列    |
| WordPiece               | 根据子词组合的关联性评分选择合并对象，逐步构建子词词表             | 能够有效学习子词结构，减少未登录词问题         | 训练过程相对复杂，分词效果依赖词表质量      | BERT      |
| Unigram Language Model  | 从较大的候选子词词表开始，根据概率模型逐步删除贡献较小的子词，保留最优词表   | 能够从多种切分方案中选择概率较高的结果，灵活性强    | 训练计算成本相对较高，依赖概率模型质量      | T5、ALBERT |
| SentencePiece           | 直接处理原始文本，将空格作为普通符号，支持 BPE 和 Unigram 等算法 | 无需依赖语言特定的预分词规则，适合多语言任务      | 本身不是独立的分词算法，实际效果依赖所采用的算法 | LLaMA、T5  |
# 疑难问题

### 为什么智能体会产生“幻觉”？

大语言模型本质上是在根据上下文预测“最可能出现的下一个词”，它的目标并不是直接判断一句话在现实世界中是否真实。因此，当模型缺少可靠信息、上下文不完整，或者问题本身比较模糊时，它可能会生成语言上非常合理、但事实错误的内容。

在智能体系统中，这个问题还会被进一步放大，因为智能体通常不是只回答一次，而是不断经历“思考 → 调用工具 → 获取结果 → 再思考 → 决策”的循环。如果某一步理解错了工具返回结果，后面的推理可能继续建立在错误信息之上，形成“错误累积”。例如：

> 用户要求智能体查询某城市天气 → 搜索工具失败 → 模型错误地假设天气为晴天 → 又基于这个错误结果推荐户外景点。

因此，智能体幻觉通常可能来自模型自身知识不可靠、输入信息不足、工具调用失败或结果理解错误，以及多步推理过程中误差不断传播。

### 为什么大模型能够听懂我们的话并根据上下文回答我们的问题？

学习了以下几个模型，总的来说也就是根据各种数学方法能够精确大模型对我们的回复


| 模型 | 工作方式（核心原理） | 主要特点 | 缺点 |
|---|---|---|---|
| **N-gram（N元语法模型）** | 统计前 N-1 个词的出现情况，预测下一个词的概率 | ① 基于统计概率；② 原理简单，容易实现；③ 不需要复杂的神经网络 | ① 无法有效理解语义；② 上下文长度固定；③ 数据稀疏问题严重 |
| **NNLM（神经网络语言模型）** | 将词转换为 Embedding 向量，通过神经网络学习词语之间的语义关系，并预测下一个词 | ① 能学习词语的语义关系；② 相似词具有相近的向量表示；③ 泛化能力较强 | ① 早期模型上下文长度固定；② 难以处理长距离依赖；③ 训练计算成本较高 |
| **RNN（循环神经网络）** | 按照顺序逐个处理词语，通过隐藏状态传递前文信息 | ① 能处理变长序列；② 具有上下文记忆能力；③ 参数跨时间步共享 | ① 长距离信息容易丢失；② 容易出现梯度消失或爆炸；③ 难以并行计算 |
| **LSTM（长短期记忆网络）** | 在 RNN 基础上引入输入门、遗忘门和输出门，控制信息的保留和遗忘 | ① 擅长处理长期依赖；② 能选择性保留重要信息；③ 缓解梯度消失问题 | ① 结构复杂，参数较多；② 计算速度较慢；③ 仍需要顺序计算 |
| **Transformer** | 利用 Self-Attention（自注意力机制），通过 Q、K、V 计算词语之间的关联，融合上下文信息 | ① 能建立长距离依赖；② 支持高效并行训练；③ 适合大规模预训练；④ 是现代主流 LLM 的基础架构 | ① 标准全注意力计算复杂度随序列长度平方增长；② 训练需要大量算力和数据；③ 需要额外的位置编码机制 |
