# 知识点

SSRF（Server-Side Request Forgery，服务端请求伪造）是一种让攻击者利用服务器自身的网络访问能力，向攻击者指定的地址发起请求的漏洞，例如访问 `127.0.0.1`、内网服务或云环境中的内部接口；**00 截断（Null Byte / `%00`）**则是利用 URL、字符串或文件路径在不同组件中对空字节 `\0` 的解析差异，使后续内容被截断，例如 `http://127.0.0.1%00www.example.com` 在某些旧版本或特定解析流程中可能被不同组件理解成不同的地址。两者本身是**不同的知识点**：SSRF负责形成“让服务器替攻击者发请求”的能力，而 00 截断有时可以作为一种**绕过 SSRF 地址校验或 URL 过滤机制的技巧**，利用“验证组件和实际请求组件解析结果不一致”来扩大 SSRF 的利用可能性；不过现代语言和框架通常已经修复了大量 Null Byte 截断问题，因此不能认为 `%00` 一定能够绕过 SSRF。
