## 题目审查

打开题目得到一个`.xlsx`文件，尝试用wps打开发现其说里面含有压缩包

于是用010editor打开文件，发现线索：

![[Pasted image 20261006112342.png]]

这是zip文件常见头，因此修改后缀及压缩包名字为“2.zip”

第一次解压后得到一个有关RC4data的`txt` 文件，以及又一个xlsx文件

根据文件题目直接将xlsx文件后缀修改，第二次解压，得到一个RC4key的压缩包，但是解压需要密码

于是猜测密码在另一个`esayrc4.xlsx`中。首先尝试修改后缀解压，但是报错：

![[Pasted image 20261006112633.png]]

于是使用bash工具string看看里面是否有什么线索：

```bash
strings esayrc4.xlsx
```

![[Pasted image 20261006113023.png]]
得到一个密码

解压压缩包得到key

解密data，得到flag

```flag
NSSCTF{ef1a73d40977a49b99b871980f355757}
```
